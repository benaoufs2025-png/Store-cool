# CoolStore · Coolray

Catalogue personnel d'applications Android pour Coolray.

- Catalogue : `https://benaoufs2025-png.github.io/Store-cool/catalog.json`
- Interface web : `https://benaoufs2025-png.github.io/Store-cool/`
- Les APK doivent être publiés dans les Releases GitHub.

Chaque entrée de `catalog.json` doit contenir une empreinte SHA-256, la taille, le nom de package et le numéro de version exacts de l'APK.
